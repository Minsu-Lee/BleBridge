BLE Bridge — 데이터 전송 샘플앱
com.jackson.blesample · Jetpack Compose · Material 3 · Phone + Tablet

GATT 서버/클라이언트 간 텍스트·이미지·영상·파일을 주고받는 메신저형 UI. 중립 그레이 + 블루/틸 역할 색상, 개발/디버깅에 필요한 전송 텔레메트리(청크·MTU·속도)를 UI를 해치지 않는 선에서 노출합니다. 라이트/다크 모두 지원.

01 · DESIGN SYSTEM

아래 foundation은 문서 전체 화면에서 역추출한 최신 기준입니다. Light/Dark, Server/Client 역할, BLE 동작 상태, 채팅 표시 모드를 독립된 의미 축으로 관리하며 기기 프레임과 문서 캔버스 색은 앱 토큰에서 제외합니다.
